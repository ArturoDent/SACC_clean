3.  .htm -> .html
Why .htm Exists: The .htm extension is a relic from the early days of personal computing. 
Older operating systems like MS-DOS and Windows 3.x used a restricted "8.3" file naming convention. 
This limited file extensions to a maximum of three characters, forcing the original .html format 
to drop its last letter. UNIX-based systems did not have this limitation and kept the full acronym.

4. pt -> px or rem
Use pt only for print: A point is an absolute physical unit equal 
to 1\72 of an inch. It is meant for physical documents, books, 
or W3C print stylesheets. If used on a screen, it scales unpredictably 
across different devices and high-density monitors.

Instead, modern web standards dictate using rem for typography:
rem is relative to the root font size: By default, most browsers set the 
root text size to 16px.1rem equals the default size: If the browser default
is 16px, then 1rem = 16px, 2rem = 32px, and 0.5rem = 8px.
Perfect Accessibility: If a user with low vision changes their base browser
font size to 20px, your rem text will smoothly scale up automatically, 
whereas px and pt text will stay locked in place.
